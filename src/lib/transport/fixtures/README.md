# Transport fixtures

## `demo-kmem-katl.jsonl` — SYNTHETIC demo data

This file is **synthetic**. It is generated by `scripts/make-demo-fixture.mjs` from a
simple kinematic profile of a Cessna 208B-style flight from KMEM to KATL. It is **not**
a recording from Microsoft Flight Simulator and must never be presented as real
telemetry. Every frame carries `source: "demo"`, and `DemoTransport` announces
`mode: "demo"` with `sim.connected: false`, so the UI shows the DEMO DATA chip.

- Format: JSONL, one `{ "t": <ms since start>, "msg": <ServerMessage> }` per line
  (see `FixtureFrame` in `packages/protocol`). The first line is a full `snapshot`;
  the rest are `delta` frames at 1 Hz plus `event` frames (`flight.started`,
  `phase.changed`, `touchdown`, `flight.ended`).
- Timeline: about 6 minutes of fixture time covering roughly 2 hours of simulated
  block time (boarding, taxi, takeoff, climb, cruise, descent, approach, landing,
  taxi-in, arrived with the parking brake set and the engine off). Positions,
  speeds and fuel are consistent with simulated time, not fixture time.
- Regenerate (deterministic, no dependencies):

  ```sh
  node scripts/make-demo-fixture.mjs
  ```

Real recordings from the connector's `--record` flag will live alongside this file
once the connector exists, named without the `demo-` prefix.
