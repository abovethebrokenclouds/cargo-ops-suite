## First-run checklist

One evening session, in this order (IDs refer to the table above). Keep
`%LOCALAPPDATA%\CargoOps\logs\connector.log` open and note anything odd in the Notes column.

1. **Without the simulator (≈ 20 min).** PC-01 start script on a clean clone → PC-17 firewall
   prompt (none expected) → PC-02 connector tests → PC-44 the first daily backup appears in
   `backups\` → PC-40 install the PWA from Edge/Chrome → PC-45 create the shortcuts (and
   `-Startup` if you want it) → PC-47 switch units → PC-42 / PC-41 basemap (online, then the local
   extract) → PC-43 refresh airports → PC-46 SimBrief: enable, enter your username, import your
   latest OFP for the flight you are about to fly → PC-48 turn on Online weather and compare the METARs with aviationweather.gov → PC-50 compare the destination TAF and the map badges too.
2. **MSFS 2024 at the gate (≈ 15 min).** PC-03 handshake and chip → PC-05 simulator name → PC-06
   no SimConnect.cfg needed → PC-07 no rejected SimVars → PC-08 / PC-09 / PC-12 values against
   the sim (pause once and change sim rate once: PC-11) → PC-16 facilities → PC-14 change
   aircraft once → PC-26 TITLE auto-match → PC-53 (1)–(3) GPS plan, EFB plan and a manual
   destination.
3. **One real mission (a short hop, ≈ 45 min).** Start `--record` (PC-15) → refresh the board at
   your gate airport, accept and load (PC-25 start-at-origin, PC-30 buy/lease if needed) → PC-53 (4) Route panel reads Mission → PC-49 set the payload stations in the sim and watch the payload check → PC-52 note the origin/destination METAR category (weather bonus) →
   PC-24 fly it: PC-10 data rate in Diagnostics, PC-19 phases, PC-21 pause and 2× sim rate briefly,
   PC-32 note IAS vs Vmo if you get close, PC-23 distance (no false teleport) → land: PC-18 /
   PC-20 / PC-27 landing grade and touchdown rate → park, engines off, brake set: payout and
   logbook → PC-53 (5) manual pick gone → PC-51 if the hop can be split, fly it as two legs with a transit stop → PC-28 GPX export → PC-29 career export/import, then **Back up now** and try the
   restore steps once (PC-44).
4. **Simulator events (≈ 15 min).** PC-13 quit and restart MSFS with the connector running →
   PC-22 crash detection (crash on purpose in a free flight) → PC-35 run tanks dry in a free
   flight → PC-36 hard landing defect rolls → PC-34 used aircraft ferry + repair loop.
5. **Later / long sessions.** PC-04 MSFS 2020 handshake → PC-37 / PC-38 AI traffic at an owned
   FBO airport → PC-31 and PC-39 month rollover and FBO accrual over a long session → PC-33
   import of an older career export.
