# Cargo Ops — Asset and Dependency Inventory

Living record required by the build directive. Every third-party component or
asset must have a row **before** it is added. Licenses were verified from the
npm registry `license` field or the project's LICENSE file on 2026-10-13 unless
marked otherwise. "Planned" rows are not yet in the repository.

Legend — Status: `present` (in `package.json` / in the repository), `planned` (approved by
the plan, not yet added), `not added` / `rejected` (considered, deliberately not used),
`ideas-only` (studied, code never copied).

**Final audit (P6, 2026-10-13):** every dependency in `package.json` and
`connector/package.json` has a row (`bun run check:inventory` passes), and every bundled asset
or data file was checked: fonts (Fontsource, OFL), map glyphs (`public/map-glyphs/`, OFL),
airports (`src/assets/data/airports-major.json`, OurAirports public domain), world outline
(`world-atlas`, Natural Earth PD), app icons and favicon (in-house), replay and SimBrief
fixtures (in-house; synthetic / hand-made), screenshots (in-house). No new runtime dependency
was added in P6.
