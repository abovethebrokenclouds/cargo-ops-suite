# Connector fixtures

## `demo-kmem-katl.jsonl` — SYNTHETIC

A copy of `src/lib/transport/fixtures/demo-kmem-katl.jsonl`, made by
`npm run fixtures:sync`. It is generated by `scripts/make-demo-fixture.mjs` from a
kinematic profile and is **not** a recording from Microsoft Flight Simulator. Do not
edit this copy; regenerate the web fixture and run `npm run fixtures:sync` again.

It states its compressed simulated clock in `sim.simTimeSec` (about 2 h of flight in
about 6 min of frames). Its `phase`/`flight` domains and `phase.changed`, `touchdown`,
`flight.*` events are authored for the browser demo; FakeSource strips them and the
connector recomputes them from the raw telemetry.

`--sim fake` replays it by default. Whatever `source` the file contains, the connector
labels every frame `source: "replay"` and announces `mode: "replay"` with
`sim.connected: false`.

## Real recordings

Record on the Windows PC with `--record <file>` (see `docs/SETUP_WINDOWS.md`). A
recording starts with a snapshot and contains frames with `source: "sim"`; it replays
with `--sim fake --fixture <file>`. Commit real recordings here without the `demo-`
prefix and note the simulator, aircraft and date in this file.

## `awc-taf.handmade.json` (HAND-MADE, not a recording)

A response of the aviationweather.gov TAF endpoint (`/api/data/taf?ids=…&format=json`) written by
hand in the documented JSON shape (`icaoId`, `issueTime`, `validTimeFrom`/`validTimeTo` in unix
seconds, `rawTAF`, `fcsts`), because the host is not reachable from the cloud container. Station
ids are real, every forecast is invented. It covers US style (FM, TEMPO, PROB30, BECMG, statute
miles) and ICAO style (metre visibility, PROB30 TEMPO, NSW); the KSEA entry lacks `fcsts` and
`issueTime` on purpose and has line breaks in `rawTAF`. Used by
`packages/weather/test/taf.test.ts`, `connector/test/weather-taf.test.ts` and the `metar-live`
workflow's TAF `--file` self-check. Once the workflow has run live, save its printed TAF response
as `awc-taf.recorded-<date>.json` next to it.

## `awc-metar.handmade.json` (HAND-MADE, not a recording)

A response of the aviationweather.gov Data API (`/api/data/metar?ids=…&format=json`) written by
hand for the weather tests (`connector/test/weather.test.ts`, `packages/weather/test/`), because
aviationweather.gov was not reachable from the cloud container (egress proxy 403, 2026-10-14).
Field names follow the API's documented JSON (`icaoId`, `obsTime`, `rawOb`, `wdir`, `wspd`,
`wgst`, `visib`, `altim`, `clouds`, `fltCat`, …); station ids are real, every value is invented.
The KORD entry lacks the decoded fields on purpose so the parser fallback is exercised. Kept
for these edge cases; real data is in the recorded file above.
